What happens when you ask a question

Question

You type in the web app

2

Router

A fast decision model picks the path and blocks unsafe requests

3

Agent

Searches documents, graph and GitHub, several times if needed

4

Check

Is the answer supported by the sources? If not, it retries

5

Answer

You: Which of my projects used FastAPI?

Assistant: “Campus Events Portal” and “Expense Tracker API”. Sources: their GitHub READMEs.

Personal Agentic RAG · 5

Here's what makes it agentic rather than plain RAG: the agent decides which tools to use and can search more than once. A small, fast "System-1" decision model handles routing and safety checks. Answers always cite their sources, which keeps the model from making things up.
