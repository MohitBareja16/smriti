Five capabilities: study, ask, fetch, track and tailor. The human-in-the-loop rule is key: anything that changes the outside world, like a LinkedIn post or a job application, is only drafted, and the user submits it.

Personal Agentic RAG · 5

Data flows left to right. Ingestion turns raw files into searchable knowledge, the knowledge store keeps it encrypted, and the agent answers questions. All models are open source and run locally, through Ollama during development.

Agentic RAG

What happens when you ask a question

1

Question

You type in the web app

2

Router

A fast decision model picks the path and blocks unsafe requests

3

Agent

Searches documents, graph and GitHub, several times if needed

4

Check

Is the answer supported by the sources? If not, it retries

5

Answer

With citations, or an honest “I don’t know”

You: Which of my projects used FastAPI?

Assistant: “Campus Events Portal” and “Expense Tracker API”. Sources: their GitHub READMEs.

Personal Agentic RAG · 6

Here's what makes it agentic rather than plain RAG: the agent decides which tools to use and can search more than once. A small, fast "System-1" decision model handles routing and safety checks. Answers always cite their sources, which keeps the model from making things up.

Personal Agentic RAG · 7

Each uploaded document and GitHub repo adds people, projects, skills and certifications to a graph. That lets the assistant answer relationship questions, and later it lets the resume update itself when a new project or certificate is added.

Security by design

Six layers protect your documents

Private network

Not reachable from the public internet

Passkey login

Fingerprint or Face ID, with no passwords to leak

Encrypted vault

Every file is encrypted at rest (AES-256)

Local AI models

No data is sent to AI companies

Guardrails

Blocks prompt injection hidden in files

Audit log

Every access and action is recorded

Personal Agentic RAG · 8

Security is the core principle. Prompt injection matters here: a malicious PDF could contain hidden text telling the AI to leak data, so retrieved text is always treated as data, never as instructions.
