# Galvin, Operating System Concepts: Main Memory chapter (student-written summary)

This is our own summary of the main memory chapter, written for revision.

## Paging in Galvin
Galvin explains paging with the hardware view: every address generated by the CPU is split into a page number and a page offset. The page number indexes the page table, which gives the base address of the frame.

Galvin stresses that paging is a form of dynamic relocation and that the page size is defined by the hardware, usually a power of 2 between 4 KB and 1 GB.

## Hierarchical and inverted page tables
Galvin describes hierarchical (multi-level) page tables to handle large logical address spaces, hashed page tables, and inverted page tables, which keep one entry per physical frame to save memory.
